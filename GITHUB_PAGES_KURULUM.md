# GitHub Pages Kurulum

Bu proje GitHub Pages için statik export ve otomatik GitHub Actions deploy ayarlarıyla hazırlanmıştır.

## Yayınlama

1. Bu paketin içindeki tüm dosya ve klasörleri GitHub reponuzun `main` branch'ine yükleyin.
2. GitHub'da `Settings > Pages` bölümüne girin.
3. `Build and deployment > Source` alanında **GitHub Actions** seçin.
4. `Actions` sekmesinde **Deploy LOTO SOP Editor to GitHub Pages** workflow'unun tamamlanmasını bekleyin.
5. Yayın adresiniz repo adına göre şu yapıda olur:
   `https://KULLANICI_ADI.github.io/REPO_ADI/`

Mevcut repo için beklenen adres:
`https://iemehmetalihoca.github.io/loto-sop-editor/`

## Not

GitHub web arayüzünde `Choose your files` düğmesi klasör seçmeyebilir. Windows Dosya Gezgini'nden çıkartılmış proje klasörünün **içindeki tüm dosya ve klasörleri seçip doğrudan Upload files alanına sürükleyin**. Alternatif olarak GitHub Desktop kullanın.
